
# 🎓 MY E-PORTFOLIO
### เว็บไซต์แฟ้มสะสมผลงานเพื่อสมัครเข้าศึกษาต่อระดับมหาวิทยาลัย

เว็บไซต์ E-Portfolio จัดทำขึ้นเพื่อรวบรวมประวัติส่วนตัว ประวัติการศึกษา ความสามารถพิเศษ กิจกรรม ผลงาน และเกียรติบัตรต่าง ๆ ของผู้จัดทำ เพื่อนำเสนอข้อมูลและประสบการณ์ที่ได้รับตลอดระยะเวลาการศึกษา สำหรับใช้ประกอบการสมัครเข้าศึกษาต่อในระดับมหาวิทยาลัย

---

## 📌 เกี่ยวกับโปรเจกต์ (About Project)

E-Portfolio เป็นเว็บไซต์แฟ้มสะสมผลงานออนไลน์ที่ออกแบบมาให้มีรูปแบบเรียบง่าย ทันสมัย และใช้งานง่าย โดยเน้นการนำเสนอข้อมูลอย่างเป็นระเบียบ เพื่อให้ผู้เข้าชมสามารถศึกษาประวัติและความสามารถของผู้จัดทำได้อย่างสะดวก

เว็บไซต์นี้พัฒนาด้วย HTML, CSS และ JavaScript โดยรวมโค้ดทั้งหมดไว้ในไฟล์ HTML ไฟล์เดียว ทำให้สามารถเปิดใช้งานผ่านเว็บเบราว์เซอร์ได้ทันที

## 🎯 วัตถุประสงค์ (Objectives)

1. เพื่อรวบรวมประวัติส่วนตัวและประวัติการศึกษา
2. เพื่อนำเสนอความรู้ ความสามารถ และทักษะของผู้จัดทำ
3. เพื่อแสดงกิจกรรมและประสบการณ์ที่ได้รับจากการเข้าร่วมกิจกรรมต่าง ๆ
4. เพื่อรวบรวมผลงานและเกียรติบัตรที่ได้รับ
5. เพื่อใช้เป็นแฟ้มสะสมผลงานประกอบการสมัครเข้าศึกษาต่อระดับมหาวิทยาลัย
6. เพื่อฝึกฝนทักษะการพัฒนาเว็บไซต์ด้วย HTML, CSS และ JavaScript

## 💻 เทคโนโลยีที่ใช้ (Technology Stack)

| เทคโนโลยี | รายละเอียด |
|---|---|
| HTML5 | ใช้สร้างโครงสร้างเว็บไซต์ |
| CSS3 | ใช้ตกแต่งเว็บไซต์และจัดรูปแบบหน้าตา |
| JavaScript | ใช้เพิ่มการโต้ตอบและ Animation |
| Google Fonts | ใช้รูปแบบตัวอักษร Kanit |

## ✨ คุณสมบัติของเว็บไซต์ (Features)

- 🏠 หน้าแรก แสดงชื่อและรูปโปรไฟล์
- 👤 ประวัติส่วนตัว
- 🎓 ประวัติการศึกษา
- 🎯 เป้าหมายในการศึกษาต่อ
- 🏆 กิจกรรมและผลงาน
- 📜 เกียรติบัตรและรางวัล
- 💡 ทักษะและความสามารถ
- 📞 ช่องทางการติดต่อ
- 📱 รองรับการใช้งานบนโทรศัพท์มือถือและคอมพิวเตอร์
- 🎨 ดีไซน์แบบ Minimal Modern
- ✨ มี Animation เมื่อเลื่อนหน้าจอ
- 📄 สามารถพิมพ์หรือบันทึกเว็บไซต์เป็น PDF ได้

## 🎨 การออกแบบ (Design)

เว็บไซต์ออกแบบในรูปแบบ Minimal Modern โดยใช้โทนสีกรมท่า สีขาว และสีฟ้า เพื่อให้เว็บไซต์มีความเรียบง่าย สบายตา และดูเป็นทางการ

เน้นการจัดวางข้อมูลให้เป็นหมวดหมู่ ใช้การ์ด (Cards) ในการแสดงผลงานและเกียรติบัตร รวมถึงมีเมนูนำทางเพื่อให้เข้าถึงแต่ละส่วนได้อย่างสะดวก

## 🚀 วิธีติดตั้งและใช้งาน (Installation)

1. ดาวน์โหลดหรือ Clone โปรเจกต์จาก GitHub
2. เปิดโฟลเดอร์โปรเจกต์
3. เปิดไฟล์ `index.html`
4. เว็บไซต์จะแสดงผลผ่านเว็บเบราว์เซอร์
5. แก้ไขข้อมูลส่วนตัวและเปลี่ยนรูปภาพให้เป็นข้อมูลของผู้จัดทำ

### การเปิดใช้งานผ่าน VS Code

1. เปิดโปรแกรม Visual Studio Code
2. เลือก Open Folder
3. เปิดโฟลเดอร์ E-Portfolio
4. เปิดไฟล์ index.html
5. สามารถใช้ Live Server เพื่อดูตัวอย่างเว็บไซต์ได้

## 📸 ส่วนประกอบของผลงาน

เว็บไซต์แบ่งออกเป็นส่วนต่าง ๆ ดังนี้

1. Home: หน้าแรกและแนะนำตัวผู้จัดทำ
2. About: แสดงข้อมูลประวัติส่วนตัว
3. Education: แสดงประวัติการศึกษา
4. Goal: แสดงเป้าหมายในการศึกษาต่อ
5. Activities: แสดงกิจกรรมที่เคยเข้าร่วม
6. Works: แสดงผลงานและความสามารถ
7. Skills: แสดงทักษะต่าง ๆ
8. Certificates: แสดงเกียรติบัตรและรางวัล
9. Contact: แสดงช่องทางการติดต่อ
